# Lessons
- 2026-10-12: mangaai-phase1.sh used set -e. Right after the first push, GitHub answered HTTP 404 (build.yml not registered yet) to the run lookup, and set -e stopped the script before the wait loop could retry. Fix: put set +e before the Auto-download lines in any script that uses set -e. The first build was then watched by running the Auto-download block by hand. The stub test had missed it because the stub never failed: test the wait loop with a stub that fails a few times first.
- 2026-10-12: a screen with display:flex ignores the hidden attribute (the author rule beats the browser default), so two screens showed at once. Fix: add `.screen[hidden] { display: none; }` whenever a class sets display on an element that uses hidden. The browser test caught it by checking is_visible on both screens.
- 2026-10-13: browser tests with Playwright (sync API) were flaky (about half the runs) when they used wait_for_function or wait_for_selector while a Python route handler had to answer a request. Fix: poll a JavaScript expression with page.evaluate and a short sleep. After the change 20 runs in a row were green. The app was fine, the test was the problem.
- 2026-10-13: a hidden file input (hidden attribute) is opened with input.click() from a normal button, and set_input_files works on it in tests. Clear its value after reading the file so the same picture can be chosen twice.
